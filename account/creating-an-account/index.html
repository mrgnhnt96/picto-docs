Creating an Account

Picto is invite-only. Redeem an invite link to get a dashboard account, a workspace, and a 14-day trial.

Everything in the dashboard — organizations, client apps, API keys, recordings, collaborators — is scoped to a dashboard account. You need one before you can integrate the recording SDK into your app.

Picto is invite-only#

There is no public sign-up. POST /auth/sign-up refuses any request that does not carry a valid invite, so an account can only be created by opening an invite link — the same rule applies whether you go through the website or call the API directly.

If you do not have one yet, join the waitlist and we will send you an invite.

Redeeming an invite#

Your invite link looks like https://picto.dev/join?t=<code>. Open it and you'll be asked for two things:

  • Your name
  • Your work email

Submitting sends a sign-in link to that address. Open the link and your account is created and signed in together — there is no password to choose and no separate verification step to wait on.

A few things worth knowing:

  • The link is single-use. Once it has created an account it cannot create another. If you need a second account, ask for a second invite.
  • Invite links expire after 14 days. So does the trial they open. An expired link is refused with a message saying so — ask whoever sent it for a fresh one.
  • The sign-in link is short-lived, and you can only request another after a minute. If it does not arrive, check spam before trying again.

What you get#

Redeeming an invite sets up a working workspace in one step:

  • an organization, named after you (rename it any time in Settings)
  • a client app inside it, with an API key ready to paste into the SDK — see Quick Start
  • a 14-day trial, with uploads switched on from the moment you land

When the trial ends, uploads stop and the dashboard explains why. Nothing is deleted — subscribe and they resume.

Signing in later#

Go to /sign-in and choose Email me a sign-in link. An account created from an invite has no password — it was never asked for one — so this is the way back in.

If you would rather have a password, use Forgot password? on the same page to set one; after that the email and password fields work as usual. Either way, signing in redirects you to /dashboard.

What this account is for#

This is a dashboard account — it identifies you as the person managing organizations and client apps, not an end user of the apps you're recording. The recording SDK itself never needs your account ID at all — every upload authenticates with a client app's API key alone (see Quick Start); your account only matters for signing in to the dashboard to manage organizations, client apps, and collaborators.

Next steps#

Your first organization and client app already exist. To add more, see Organizations & Client Apps.
